# Issue documentation split

The new per-finding and per-session files avoid list insertions and renumbering;
independent files for the open run-order and repository-display PR findings
prevent conflicts with the migration branch's shared landing page. Historical
finding text and observations were checked for preservation, and all local
Markdown links resolve. One caveat: keeping a complete old finding log as an
archive still risks later edits targeting that archive, so new observations
must go only into dated files.
