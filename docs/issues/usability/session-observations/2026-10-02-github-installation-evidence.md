# GitHub App installation authorization evidence

- **Type:** Research observation for the REST MVP's installation/repository authorization gate; not a user-reported finding.
- **What worked:** GitHub's App user-token guide says the token can access only repositories shared by both the user and the App, and points to `GET /user/installations` and `GET /user/installations/{installation_id}/repositories` to inspect accessible installations and repositories. The REST endpoint docs confirm these endpoints accept GitHub App user access tokens; listing installations requires no permission, while listing repositories for an installation requires Metadata: read. The repository response includes the user's access permissions.
- **Evidence limits:** This documents available checks, not a decision to expose user-selected installation IDs, bind a principal to one installation, or query a particular installation at OAuth callback. Existing design still requires checking actual target authorization; the intended account/repository selection and cross-repository rules remain open.
- **Scope status:** Added the source links and a design gate that records these API checks as available options without choosing installation-selection behavior. No authorization flow, API call, route, permission set, or runtime behavior was implemented.
- **References:** [GitHub App user access token](https://docs.github.com/en/apps/creating-github-apps/authenticating-with-a-github-app/generating-a-user-access-token-for-a-github-app); [List app installations accessible to the user access token](https://docs.github.com/en/rest/apps/installations#list-app-installations-accessible-to-the-user-access-token); [List repositories accessible to the user access token](https://docs.github.com/en/rest/apps/installations#list-repositories-accessible-to-the-user-access-token).
- **Friction:** Search remained unavailable in this environment; direct retrieval of the GitHub REST Apps installations page provided the endpoint descriptions, supported token types, and permission requirements.
