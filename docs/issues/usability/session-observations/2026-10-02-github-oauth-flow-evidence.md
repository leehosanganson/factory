# GitHub App authorization-flow evidence audit

- **Type:** Research session observation for the REST MVP authorization design gate; not a user-reported finding.
- **What worked:** GitHub's dedicated GitHub App user-access-token docs describe the web application flow separately from OAuth App flow, identify `https://github.com/login/oauth/authorize`, mark `client_id` required, recommend `redirect_uri`, random `state`, and PKCE, require `S256` when PKCE parameters are supplied, and require the corresponding `code_verifier` at exchange when a challenge was sent. The callback URL docs say up to 10 callback URLs may be registered and that the first is selected if `redirect_uri` is omitted. The GitHub App docs list `client_id`, `client_secret`, and `code` as required at token exchange.
- **Evidence limits:** The GitHub App web-flow parameter table does not list `response_type`; that does not establish whether it is rejected. Its fetched docs do not document authorization-stage denial/error callback parameters or an authorization-code expiry. OAuth App callback error documentation is a distinct flow and should not be generalized to GitHub Apps. Installation selection and exact authorization URL choices remain unapproved design gates.
- **Scope status:** Findings were added to the credential-custody design and the REST contract tracking status was updated. No OAuth flow, routes, or runtime behavior were implemented; no flow choice was made.
- **References:** [GitHub App user access token web flow](https://docs.github.com/en/apps/creating-github-apps/authenticating-with-a-github-app/generating-a-user-access-token-for-a-github-app); [GitHub App callback URLs](https://docs.github.com/en/apps/creating-github-apps/registering-a-github-app/about-the-user-authorization-callback-url). The separate [OAuth App authorization-error guide](https://docs.github.com/en/apps/oauth-apps/maintaining-oauth-apps/troubleshooting-authorization-request-errors) was inspected only to identify evidence that must not be generalized to GitHub Apps.
- **Friction:** Search was unavailable in this environment. Direct retrieval of the official GitHub Docs pages provided useful parameter tables; raw retrieval was needed because readable page extraction omits some structural details.
